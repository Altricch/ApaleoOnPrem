Local apaleo core API

Every operation documented in apaleo's ten v1 specifications, implemented against a local database. Pick an operation on the left to see its contract and run it against this server.

Authentication

Anonymous access is enabled by default, so you can call any endpoint straight away. To exercise the real flow, request a token and send it as a bearer header. 

curl -s -X POST http://localhost:8088/connect/token \
  -d grant_type=client_credentials \
  -d client_id=apaleo-clone \
  -d client_secret=secret

Demo data

npm run seed loads two properties, 24 units, ten rate plans with a year of rates, and reservations spread across past, present and future. 

curl -s "http://localhost:8088/booking/v1/offers\
?propertyId=MUC&arrival=2026-06-01\
&departure=2026-06-03&adults=2"
